# ShopScope 五分钟展示提纲

打开 `app/index.html` 即可离线查看，不需要安装前端框架或启动服务。页面只使用管线产出的汇总结果，不包含逐访客行为轨迹。

## 1. 用半分钟说明问题

本项目使用 Retailrocket 公开电商行为数据，围绕购物路径、人群差异和推荐效果三个问题组织分析。SQL负责清洗、口径与聚合；后续推荐评估与模拟实验分别展示策略比较和决策方法。

## 2. 用一分钟讲清数据和路径

先看全观测期的事件、访客与访问概况，再切换每日趋势中的浏览、加购与购买。尝试选择一个日期区间，说明日期筛选只改变趋势图，其他板块保留原评估范围。

路径以“访问×商品配对”为单位，要求同一访客、同一访问、同一商品内严格时间顺序。浏览后购买与严格三步路径分别计算，避免把直接购买强行归入加购路径。展开明细表核对一个分子和分母。

## 3. 用一分钟比较推荐策略

在验证集与测试集之间切换。热门推荐作为基线，共同浏览推荐使用训练期关联；缺少关联时采用预先规定的热门回退。“完全回退热门”只计没有任何共同浏览候选的预测点，列表中部分热门补足不计入该比例。

解释两项指标：Hit Rate@10是全部合格样本中，下一次浏览的不同商品出现在前10个推荐里的比例；Coverage@10是固定候选商品中至少被推荐过一次的比例。结合真实结果解释命中、覆盖与回退的取舍，并阅读按访客重采样的两策略差异区间，不将离线差异说成线上收益。

## 4. 用一分钟展示实验思路

模拟实验采用用户级随机分组和固定种子。先检查分组比例，再解释处理差异及95%置信区间。区间使用“百分点”单位；是否跨越零、以及分组是否异常，分别对应效果不确定性和数据质量问题。

## 5. 用一分钟说明可复现性与个人分工

展示数据来源、输入文件校验值、SQL与管线入口。下载看板结果JSON，说明它与报告和图表来自同一份计算产物。

本轮作品由AI辅助完成工程和分析实现；个人在准备面试时应能说明数据口径、比较方法及关键查询。作品完成状态与课程学习进度分别记录。

## 本地重新构建看板

在项目目录运行：

```console
python app/build_dashboard.py
```

默认读取`reports/metrics.json`。脚本会检查必要数据板块以及非有限数值，再把CSS、JavaScript和汇总结果嵌入一个HTML文件。没有外部字体、图表库或网络请求。
